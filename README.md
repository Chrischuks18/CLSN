# CLSN Enugu 2026

Digital programme for the 38th Annual Convention of the Canon Law Society of Nigeria, 27–30 October 2026.

## Publish

In GitHub Settings → Pages, choose Deploy from a branch, main, /(root). The intended custom domain is www.clsn-enugu.org. In Namecheap set the www CNAME to chrischuks18.github.io (replace any earlier ChatGPT Sites target). Enable HTTPS when GitHub confirms the domain.

## Update

Edit data.json for sessions and presenters. Upload papers to assets and update the presenter cards in app.js when the papers become available. The current buttons are marked Coming soon. Uploaded presenter photographs are not yet available.

The original Word programme and official flyer are in assets. Print/save as PDF includes all four days.
